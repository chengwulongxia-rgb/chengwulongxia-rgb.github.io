過去三天的新增資訊集中在同一種產品形態：模型更便宜、代理更能長時間自行工作，甚至開始替人進入交易環境。來源同時揭露了適用範圍、實驗條件與仍未解決的委託問題；模型分數、代理權限和它是否真的理解使用者，不能用同一個數字代替。

## 🔥 GPT-6.1 Sol 以 GPT-6 Astra 五分之一的標準 token 價格提供 API

OpenAI 發布 GPT-6.1 Sol，官方定價為每百萬 input tokens 2 美元、cached input 0.10 美元、output 10 美元；GPT-6 Astra 的標準價格則是 input 10 美元、output 50 美元、cached input 1 美元。OpenAI 表示，Sol 在 DeepSWE v1.1、GDP.pdf、AutomationBench、OSWorld 2.0 與 Terminal-Bench Science 0.1 等測試中接近或部分超過 Astra 以外的模型，但這些比較由 OpenAI 的研究環境或 API 執行，競品數據取自公開報告，測試條件不一定相同。

在 OpenAI 列出的結果中，Sol 在 Terminal-Bench Science 0.1 的最高推理設定分數為 68.1%，Astra 仍是測試模型中最高者；Sol 每項任務平均成本為 5.47 美元，Opus 5.5 為 23.21 美元、Astra 為 23.80 美元。OpenAI 也把 factuality 測試限定為使用者曾回報錯誤的困難對話，Sol 的錯誤回答比例由 GPT-6 Sol 的 11.4% 降至 7.7%，官方明確說這些題目不代表一般使用情境。

模型目前可透過 API 使用，ChatGPT 端尚未開放；ChatGPT Work 與 Codex 則向 Plus、Pro、Business、Enterprise 和 Edu 使用者推出。安全評估同樣是刻意挑選的困難情境，不是一般使用的失敗率。OpenAI 的系統卡附錄列出它在搜尋工具故障揭露測試中仍有 2.1% 的未揭露比例，低於 GPT-6 Sol 的 4.9%，但高於 Astra 的 1.5%。

- 來源：[openai.com](https://openai.com/index/introducing-gpt-6-1-sol/)

## OpenAI 推出 Dots，讓代理在雲端電腦上持續執行任務

OpenAI 發布 Dots：每個 dot 有自己的雲端電腦與瀏覽器，使用 GPT-6 Astra，可連接超過 4,000 個應用程式，並能在 ChatGPT、Slack 和 Teams 接收訊息。官方展示的工作包括讀取客戶回饋後建立並測試修正、依新資料重跑分析、更新提案，以及替內容工作產生草稿；這些案例是產品方描述的工作流程，不是跨使用者的完成率或錯誤率測試。

Dots 可以在背景進行「proactive research」。這個模式使用已連接應用程式的唯讀工具，不能傳送訊息、修改應用程式內容或控制瀏覽器與電腦。若使用者另外授權連接自己的筆電，代理可以直接在該裝置旁工作；權限由既有 ChatGPT 控制項和 Custom Rules 管理，特定敏感操作，例如改密碼，仍須由使用者完成。

OpenAI 表示，Dots 會以 auto-review 檢查可能影響帳戶或分享資訊的動作，並依指令、規則與安全要求決定是否需要核准；官方也寫明 Dots 仍可能犯錯，重要工作必須人工檢查。Dots 正在 Pro、Business Premium 與 Enterprise 的符合資格市場推出，Enterprise、Edu 和 Healthcare 需要管理員啟用 beta；個人方案的對話與工作是否用於改進模型，仍取決於使用者設定，商務、企業與教育工作區預設不使用其內容改進模型。

- 來源：[openai.com](https://openai.com/index/introducing-dots/)

## Anthropic 的 Project Swap：代理談判的瓶頸先出現在「是否理解你」

Anthropic 讓 201 名、分布於六個辦公室的員工各自交出一本書，再用 Claude 代理在交易場交換書籍。代理先透過短對話推測使用者對書籍的偏好，再在公開交易場提出交換、接受或拒絕提案。使用者實際排名與 Claude 預測排名的成對一致率為 61%，隨機猜測基準為 50%；研究也指出，輸入對話從 150 字增加到 300 字，預測一致率約增加 4 個百分點。

在這個設定中，參與者最後拿到的書籍平均落在自己十本排名中的約第五名，市場效率為 0.55；若用理想化的最佳分配，效率為 0.89。研究方將落差主要歸因於代理對使用者偏好的表示不完整，而不是交易規則本身。以 Claude 自己的偏好排名計算時，Haiku 交易場平均效率為 0.75、Opus 為 0.88、Fable 為 0.86；這些結果來自 Anthropic 自行設計的書籍交換實驗，不等於代理在金融、醫療或其他真實市場中的表現。

實驗中的代理都由 Anthropic 建立、使用 Anthropic 模型，代表已確認身分的公司員工，並在規則明確、交易紀錄公開的交易場運作。研究也記錄了書籍未帶到現場、無法追蹤交付等流程問題，並指出真實市場還需要處理代理註冊、身分、訊息速率、違約、退款和責任歸屬。Anthropic 的研究結論是，讓代理代替人談判之前，除了測試一般能力，也需要先用樣本決策檢查它是否正確代表特定使用者。

- 來源：[anthropic.com](https://www.anthropic.com/research/project-swap)

## TurboGPT 用 CUDA C++ 訓練可在不到一分鐘完成的微型 GPT

GitHub 專案 TurboGPT 提供以 CUDA C++ 撰寫的 byte-level GPT 訓練程式，作者將其定位為「在不到一分鐘訓練 tiny GPT」。專案需要 NVIDIA CUDA，Linux/NixOS 以 Nix 建置，Windows 則使用 Visual Studio 2022 C++ 工具和 CUDA 13.4；目前公開儲存庫有 9 次 commit、29 顆 star，採 MIT 授權。

README 的示例結果是在 15 億個 training tokens 後，模型達到 2.5295 BPB；儲存庫同時提供 checkpoint、報告輸出與 Python 驗證測試。這些資料說明專案包含可執行的訓練與測試路徑，但沒有提供模型參數量、資料集組成、完整硬體規格或與其他訓練實作的控制組比較，因此「不到一分鐘」不能直接解讀成一般 GPT 訓練工作的時間。

- 來源：[github.com](https://github.com/lostmsu/TurboGPT)
