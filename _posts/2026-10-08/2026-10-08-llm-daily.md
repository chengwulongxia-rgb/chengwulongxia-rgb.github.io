這三天的新增消息集中在模型如何被使用：Anthropic 把小模型定位到高量、低成本的代理工作，OpenAI 讓 ChatGPT 直接生成互動介面，Docker 將 agent 的設定與工具連接整理成 YAML，而一項小型模型比較則把「多數模型同意」和「答案正確」分開。能力、價格與使用介面正在同時成為模型產品的一部分。

---

## 🔥 Claude Haiku 5.5 針對高量任務降價，複雜 coding 仍由大模型處理

Anthropic 發布 Claude Haiku 5.5，定位為處理摘要、資料庫查詢、分類、即時客服與瀏覽器操作等高量任務的模型。官方列出的 API 價格是每百萬 token：輸入 0.10 美元、輸出 0.50 美元；prompt 超過 100,000 token 時，價格分別為 0.50 與 2.50 美元。快取讀取是 0.01 美元，寫入是 0.125 美元，長 prompt 的價格另有一組費率。

Anthropic 的比較表列出 Haiku 5.5 在 Terminal-Bench 4.0 得分 39.2%，Haiku 4.5 為 0%，GPT-6 Luna 為 16.4%，Sonnet 5.5 為 70.6%。同一份公告也明確表示，Sonnet 5.5 與 Opus 5.5 仍較適合複雜的 agentic coding；Haiku 5.5 的使用範圍主要是較窄、可大量重複的工作。這些結果來自 Anthropic 列出的評測流程，並非獨立測試。

Anthropic 表示，Haiku 5.5 已在 Claude Platform、Amazon Web Services、Google Cloud 與 Microsoft Azure 提供，並對生物與資安相關請求套用既有的限制；較廣泛的生物或資安活動需要申請驗證計畫。公告也提到更新 tokenizer 會讓模型在完成同一工作時使用稍多 token，因此「單價降低」與實際每項工作的總成本不是同一個數字。

- 來源：[anthropic.com](https://www.anthropic.com/claude-haiku-5-5)

## GPT-6 在 ChatGPT 加入可互動介面，企業版是否啟用由管理員設定

OpenAI 宣布 GPT-6 開始在 ChatGPT 全球推出，並把 Intelligent UI 納入這次更新。官方說法是，模型可以在文字之外產生圖表、按鈕、表單、互動圖解與小型工具；系統以元件庫和編譯器讓介面隨模型輸出逐步顯示。公告中的示例包括自行車結構圖、晚餐分帳工具、退休儲蓄計算器與可在對話中玩的遊戲。

OpenAI 同時表示，GPT-6 能在持續推理時開始回覆，GPT-6 Instant 在需要網路搜尋的問題上平均比 GPT-5.6 Instant 早 44% 開始回答；GPT-6 Extra High 在一項內部 agentic task 評估中，開始回答的時間與 GPT-5.6 Medium 相同，但整體分數高於 GPT-5.6 Extra High。這些數字都來自 OpenAI 的內部評估，公告未提供完整測試題目與外部重現結果。

GPT-6 with Intelligent UI 先向 ChatGPT Plus、Pro、Business 與 Enterprise 推出，隔日擴展至 Free 與 Go。Plus、Pro、Business、Enterprise 使用 GPT-6 Sol，Free 與 Go 使用 GPT-6 Luna；Enterprise 是否可用取決於工作區管理員設定。這次更新只涉及 ChatGPT 的 Chat experience，Work 與 Codex 使用的模型不在變更範圍內。OpenAI 的 system card 另說明了安全與限制測試，但介面能否正確表達資料、操作與權限，公告未以獨立評估呈現。

- 來源：[openai.com](https://openai.com/index/gpt-6-for-everyone/)

## Docker Agent 以 YAML 定義 agent，工具連接與遙測仍需自行處理

Docker 公開 `docker/docker-agent`，將 agent 的模型、提示、工具與多 agent 協作設定放進 YAML，透過 `docker agent run agent.yaml` 執行。README 列出的工具路徑包括本地、遠端或以 Docker 執行的 MCP server，也支援 Docker Model Runner 和其他模型供應商；專案另外提供 RAG、TUI、CLI、套件分享與多 agent 文件。

README 的範例以 `openai/gpt-5-mini` 作為模型，並透過 MCP 工具連接 DuckDuckGo。安裝方式包括 Docker Desktop、Homebrew、二進位發布檔與 CLI plugin；使用雲端模型至少要設定一組 API key，也可以改用 Docker Model Runner 的本地模型。專案以 Apache-2.0 授權，GitHub 頁面列出約 3,800 顆 stars 與 487 個 forks。

Docker 將它描述為 agent builder and runtime，但 README 沒有把「可用模型」或「可用工具」變成單一內建清單，實際能力取決於 YAML、供應商憑證、MCP server 與本地環境。專案也明確說明會收集匿名使用資料以改善工具；使用者需要另外查看遙測文件與設定方式。

- 來源：[github.com](https://github.com/docker/docker-agent)

## 一項 12 模型排名測試：共識分數不等於答案正確

Magic Numbers 的作者用 `top3.best` 讓 12 個模型回答同一類「前三名」問題，再把每個模型的排名和其他 11 個模型的結果比較。每個項目若和群體共識的名次相同得滿分，項目相同但名次不同得半分；作者用 Gemini Flash 對不同寫法進行名稱歸一化。

在這組測試中，DeepSeek、Kimi K2、Tencent Hy3 與 GLM 的共識分數位於前段，Meta Llama 4 Scout 與 Anthropic Claude Haiku 位於後段；作者按地區計算時，五個中國模型平均 0.47，六個美國模型平均 0.38，Mistral 這個歐洲樣本為 0.36。這是特定模型、特定提示語、英文問題與一次測試工具的結果，不是模型品質或事實正確率的通用排名。

文章列出的限制包括資料集規模小、模型組合任意、共識不代表正確，以及問題使用英文。五個中國模型同時參與建立「其他模型」的比較基準，也可能使同一群體的相似回答提高彼此的分數；文章提出蒸餾、共同訓練資料、模型大小、知識截止日期與 post-training 個性等可能解釋，但沒有把任何一項證明為因果來源。

- 來源：[magicnumbers.io](https://magicnumbers.io/2026/10/06/ai-model-groupthink/)
