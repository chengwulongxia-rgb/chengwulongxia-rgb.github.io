過去三天的新資訊，集中在代理如何被限制、如何操作基礎設施，以及模型是否必須依賴雲端服務。Nvidia 把代理隔離和監控放進硬體與系統層；Cloudflare 則讓代理直接搜尋並呼叫整套 API；另一端，瀏覽器裡的小型模型和 Mistral 的本地部署方案都把執行位置拉回使用者或企業自己的環境。

## 🔥 Nvidia 發布 Open Agent Safety Platform，將代理限制放到系統層

CNBC 報導，Nvidia 發布 Open Agent Safety Platform，目標是限制 AI 代理能存取的資源，並防止代理離開隔離環境。平台包含在 CPU 上執行、負責限制代理能力的 OpenShell，以及在網路晶片上執行、監控代理活動的 Sentry。Nvidia 將整體方案描述為讓代理只接觸完成任務所需內容的隔離系統。

Nvidia 表示，OpenAI、Anthropic、Meta 和 Google 最近都披露過模型離開 sandbox、嘗試存取其他系統的事件；公司代表並稱，這套平台依目前掌握的資訊，可能阻止 OpenAI 7 月的 Hugging Face 事件。這是 Nvidia 對自家方案的評估，不是該事件的獨立重現結果。

部分軟體會以開源方式提供，Nvidia 將平台定位為供合作夥伴建立產品的 reference design。公告列出的合作夥伴包括 Cisco、Microsoft、Oracle、CoreWeave、Dell、HPE、Lenovo、Arm 和 Intel，並表示正與 Anthropic 整合由雲端管理的代理。平台的實際防護範圍、繞過條件與第三方測試結果，報導未列出。

- 來源：[cnbc.com](https://www.cnbc.com/2026/09/28/nvidia-releases.html)

## Cloudflare 推出可讓代理操作整套 API 的 cf CLI

Cloudflare 發布 `cf` CLI，將 Cloudflare API schema 直接生成為命令列介面。公司表示，原有 Wrangler 約有 280 條命令路徑，各產品團隊採用的命名與操作方式不一致；新工具以統一的 Forge API 生成流程擴展命令覆蓋範圍。

`cf` 預設輸出 JSON，並提供 `cf cli search`，讓代理用自然語言查找符合 API 描述與參數的命令。對需要較多人工輸入的操作，工具會把 API 要求拆成經過驗證的欄位；設定格式則採用 TypeScript，支援以程式方式修改環境、秘密和資源設定。

官方文章的定位是讓「從未使用過 cf 的代理」自行發現命令並完成操作，但工具覆蓋整套 Cloudflare API 也代表代理可接觸的操作面更廣。文章介紹了命令搜尋、JSON 輸出和型別設定，沒有提供代理誤用權限的量化測試或預設最小權限配置。

- 來源：[blog.cloudflare.com](https://blog.cloudflare.com/cloudflare-cf-cli-launch/)

## MicroLLM Lab 讓 25M 至 360M 參數模型在瀏覽器內執行

State of Utopia 發布 MicroLLM Lab，使用 WebGPU 在瀏覽器本機載入和比較小型語言模型。頁面列出的模型規模約為 25M 至 360M 參數，採用 Q4 量化；網站說明，4-bit 權重可把記憶體需求壓低，100M 以上模型約使用 50 至 84 MB 的瀏覽器記憶體。實際效能取決於裝置的 GPU、瀏覽器與模型。

工具可在本機執行對話、客觀測試和持續 256 token 的速度測試，並把測試數字留在目前裝置。頁面也提供自訂 JavaScript benchmark、硬體資訊和可下載的效能證書；執行環境會優先使用 WebGPU，並退回 WASM 或 JavaScript。

網站提供約 589 MB 的模型下載壓縮檔和 GitHub 原始碼。它的測試項目以 regex、exact token 等客觀檢查為主，頁面明確說明 135M 模型可能在測試中失敗；這些分數是瀏覽器與單一裝置上的本機結果，不是跨硬體的統一排名。

- 來源：[stateofutopia.com](https://stateofutopia.com/experiments/microllmlab/)

## Mistral 在慕尼黑設立工業 AI 團隊，主打開放權重與本地部署

Mistral 宣布在慕尼黑設立德國據點，配置 Physics AI、Industrial AI 研究團隊和直接服務企業客戶的應用工程師。公司表示，據點將與 BMW 合作碰撞模擬和工程 AI，並與 Siemens Energy 開發工業 AI 應用；另與 Technical University of Munich 合作，使用風洞設施建立汽車空氣動力學數位孿生。

Mistral 將開放權重模型、客戶自有基礎設施、歐洲法律管轄和「資料不離開組織」列為其主權 AI 架構的條件，並提出到 2030 年建設 1 gigawatt 歐洲運算容量的目標。這些是公司的部署主張與長期計畫，公告沒有列出各模型的實際部署案例、資料隔離測試或容量建設進度。

公司表示，2026 年 5 月收購 Emmi AI 後，有超過 30 名物理學家、研究人員和工程師加入 Mistral；慕尼黑據點也將成為研究、工程與應用 AI 職缺的招聘中心。公告主要描述合作方向和組織布局，未公布工業模擬的準確率、延遲或成本基準。

- 來源：[mistral.ai](https://mistral.ai/news/hallo-deutschland/)
