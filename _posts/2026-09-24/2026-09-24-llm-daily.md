這一批新聞同時出現兩種不同的自動化：Anthropic 讓 Claude 參與從 DNA 資料庫搜尋到生物實驗候選的流程；另一項獨立測試則發現，Claude Code 在特定隱私設定下可能靜默跳過本機的 AGENTS.md。模型能做什麼之外，流程是否真的執行、誰能驗證結果，仍然是部署時的實際條件。

## 🔥 Anthropic 稱 Claude 找到具 CRISPR 類重複序列的新酵素系統

Anthropic 9 月 23 日公布一項早期生命科學研究，表示 Claude 代理從大量 DNA 序列中辨識出一個此前未被描述的系統，命名為 array-associated reverse transcriptases（ART）。這個系統主要出現在噬菌體中，由 reverse transcriptase、相鄰的夥伴基因，以及一長串間隔規律的 DNA 重複序列組成；初步實驗顯示，重複序列也會表達成多條短 RNA。

研究流程先收集超過 200,000 個 reverse transcriptase，篩出 3,500 個候選系統，再縮小到 20 個候選進行報告與分析。Anthropic 表示，約 950 個代理在 21 小時內使用 2.1 億個 token 搜尋資料；人類科學家負責實驗與審查。公司目前仍不知道 ART 的主要功能，也尚未宣稱它具有 CRISPR 系統可用的基因編輯能力。

Anthropic 表示，實驗室只進行 BSL-1 與 BSL-2 等級的工作，不處理可感染人類的病原體；完整細節另載於預印本。這次公布的是候選系統的辨識與初步表徵，ART 能否成為可編程的生物技術工具，仍取決於後續功能研究。

## Claude Code 的 AGENTS.md 載入可能受遙測設定影響，且不提示使用者

部落格作者 Przemek Szypowicz 測試 Claude Code 2.1.277 的 AGENTS.md 支援後，指出載入器位於名為 `agents-md` 的內建 plugin，並受遠端 feature flag `tengu_agents_md_mod` 控制。作者以只含 AGENTS.md 和 canary 字串的空目錄測試，觀察到設定 `CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC=1` 或 `DISABLE_TELEMETRY=1` 時，Claude Code 不會讀取該檔案。

作者也測試了將上述環境變數設為 `0`、在 `settings.json` 設定環境，以及透過命令列對第二個 session 覆寫設定；文章記錄的結果顯示，前幾種情況都沒有警告，模型只會像沒有收到專案指令一樣回答。作者引用 Anthropic GitHub issue #95690 指出，第三方 gateway、Bedrock 和 Vertex 也可能因無法解析這個遠端旗標而遇到相同問題。

文章提出的暫時做法是在 `CLAUDE.md` 寫入 `@AGENTS.md`，讓同一份本機檔案透過明確引用載入。這是單一作者的測試與原始碼觀察，不是 Anthropic 的正式根因說明；目前可確認的是測試條件、靜默失敗現象與 workaround，不能據此推論所有版本或所有部署方式都會發生相同結果。

- 來源：[blog.szypowi.cz](https://blog.szypowi.cz/p/claude-code-reads-agents.md-only-when-telemetry-is-on/)

## Mercury 2.5 以輸出速度取向，Artificial Analysis 測得每秒 780.8 token

Artificial Analysis 的 Mercury 2.5 模型頁面列出，Inception 的 API 在其測量中達到每秒 780.8 個輸出 token，首次 token 延遲為 2.91 秒；模型的 Artificial Analysis Intelligence Index 得分為 12。該頁面將 Mercury 2.5 的輸出速度與同價位 reasoning models 的中位數 111.8 token/秒並列，但這些數字依賴測試方法、服務商與請求條件，不能直接等同於所有任務的完成時間。

頁面列出的 API 價格是每百萬輸入 token 0.25 美元、輸出 token 0.75 美元，context window 為 260K token，模型支援文字輸入與輸出，不支援影像。Mercury 2.5 是 proprietary model，模型權重未公開；頁面顯示目前有一個 API provider。

同一頁面把 Intelligence Index 得分 12 描述為低於相近價位 reasoning models 的中位數 13，因此速度與能力指標在這組資料中並不朝同一方向。Mercury 2.5 的發布日期標為 2026 年 9 月 8 日，並非本日新發布；本次列入是因為最新素材提供了可核對的速度、延遲、價格與能力指標。

- 來源：[artificialanalysis.ai](https://artificialanalysis.ai/models/mercury-2-5)
