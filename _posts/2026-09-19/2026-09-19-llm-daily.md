## 🔥 安全研究團隊披露：漏洞鏈曾取得 OpenAI 內部 repo 的寫入能力

Hacktron AI 發表的研究記錄一條由 Discourse 論壇映像處理漏洞與 OpenAI SSO 設定問題組成的攻擊鏈。研究團隊表示，他們先利用 `libheif` 的 heap buffer overflow，在 OpenAI 使用的 `community.openai.com` 取得遠端程式碼執行，再利用 SSO 連結取得 ChatGPT／Codex 帳戶存取權，最後讓一名員工帳戶連接的 Codex 在 OpenAI 內部 monorepo 開出一個 pull request，以此證明影響範圍；團隊稱未進一步讀取內部程式碼。

研究者表示，從首次發現到取得 repo 存取能力不到 72 小時，OpenAI 約 14 小時後確認已修正 OpenAI 端問題，Discourse 隔日準備修補程式。文章指出，漏洞利用需要人類研究者引導，並非全程自主；但研究團隊稱 Claude Opus 5 在他們的測試中，能把先前版本未完成的 exploit 轉成可用於目標環境的版本。這些結果來自 Hacktron 自己的研究，不是對所有模型或部署環境的獨立測試。

Hacktron 也列出修補條件：更新發行版或上游的 `libheif`、`libde265` 安全套件，並以 ImageMagick security policy 等方式增加隔離。文章把研究對象描述為跨多個使用 `libheif` 的軟體生態，實際是否受影響仍取決於版本、發行版 backport 與部署設定。

## Needle 3 以 8–29 MB 模型在裝置端執行工具呼叫

Cactus Compute 發布 Needle 3，一組面向手機、穿戴式裝置、機器人、車載系統與微控制器的 automation foundation model。官方資料顯示，模型採用同一組權重的 2 至 20 層 subnetwork，量化後二進位檔大小約 8–29 MB；完整模型有 29–121M 參數，訓練資料為 3,600 億 tokens 的 proprietary structured dataset。

Needle 3 的輸出集中在工具呼叫、結構化抽取與文字 embedding。官方範例讓模型根據工具描述產生 JSON function calls，也可依 schema 從發票或通知中抽取欄位；其 grammar 用於保證輸出可解析。Cactus 表示，模型在 Raspberry Pi 5 上可達每秒 400–4,000 tokens decode、每秒 1,000–10,000 tokens prefill，數字是專案方公布的測試結果。

Cactus 也宣稱，4 層 subnetwork 在針對下游任務 fine-tune 一個 epoch 後，可在該任務上匹敵 DeepSeek V4 Flash；其 DroidCall 測試集只有 200 筆資料，Mobile Actions 測試集有 961 筆資料。這些是特定工具呼叫與抽取測試，不代表 Needle 3 在一般對話或未見過的任務上具備相同表現。

- 來源：[cactuscompute.com](https://cactuscompute.com/needle)

## OpenAI 以 LLM 協助 Jalapeño 加速器的前端設計

IEEE Spectrum 報導 OpenAI 的 Jalapeño AI accelerator 從第一個架構概念到 first silicon 不到 20 個月，從第一份 RTL 到 tape-out 約 9 個月。專案平均不到 100 人，Broadcom 負責從 gates onward 的 physical design；OpenAI 負責系統設計、inference accelerator、memory hierarchy 與 networking。

OpenAI 團隊以 Google 開源的 Accelerated Hardware Synthesis（XLS）為前端工作流基礎，讓模型協助處理較接近程式碼的 DSLX、C++ 與 Verilog 工作。IEEE Spectrum 引述 OpenAI 表示，第一批晶片在 2026 年 5 月回來後，內部 AI 模型協助把 DeepSeek multi-head latent attention kernel benchmark 的表現，從理論上限的 0.31% 提升到 88.94%，約耗時 40 小時；OpenAI 稱結果可重現，但文中未提供獨立測試資料。

報導同時區分前端與後端：Jalapeño 的多數 backend design 由 Broadcom 處理，OpenAI 只公布 AI 輔助 physical design 讓 matrix multiplication units 相對於 optimized human baseline 面積減少 10% 的說法。OpenAI 的硬體主管也表示，Codex 目前不能讓任何人單獨建造 state-of-the-art accelerator，工程師仍負責判斷與驗證。

- 來源：[spectrum.ieee.org](https://spectrum.ieee.org/llms-for-chip-design)

## Claude Code 變更專案指示檔讀取規則

Claude Code changelog 的最新條目列出，當專案沒有 `CLAUDE.md` 時，Claude Code 會讀取 `AGENTS.md`。這項變更影響 agent 啟動時取得專案規範的檔名 fallback；現有的檔案內容、優先順序與衝突處理仍由工具的設定與文件規則決定。

- 來源：[code.claude.com](https://code.claude.com/docs/en/changelog)
