過去三天的素材聚焦在模型如何處理更大的工作範圍：Google 把 Gemini 4 Hydrogen 放進全球搜尋，研究者用 Qwen3-1.7B 觀察多語言對話在殘差流中的幾何分布，另一篇教學則整理近期模型採用的 positional encoding；OpenAI 同時把機器人研究併入一般模型與 Applied 組織。以下區分官方公告、單一模型實驗與媒體報導，不把個別測試直接延伸成普遍結論。

## 🔥 Google Search 全球導入 Gemini 4 Hydrogen

Google 11 月 12 日宣布，Gemini 4 Hydrogen 已在 Google Search 全球提供。官方列出的更新包括理解多部分問題、同時展開多個查詢、連結更多相關網站，以及在結果中呈現圖片、結構化比較表與自訂工具。公告將這些功能描述為適用於所有支援 AI 模型的語言，但沒有列出各地區、查詢類型或帳戶的個別開放條件。

Google 說 Search 會使用 Hydrogen 處理較複雜的意圖，並讓使用者以自然語言描述旅遊、購物或興趣上的條件。頁面中的摘要與語音內容另標示為 Google AI 產生、屬於實驗性功能；公告沒有提供獨立評測、錯誤率、查詢延遲或與前一版本的可重現比較數據。

這項更新是 Search 產品公告，不是 Gemini 4 Hydrogen 的完整模型規格。Google 在此頁列出的是搜尋體驗層級的功能變更，沒有說明每個查詢是否都會使用 Hydrogen，也沒有公布結果排序、引用來源選擇及「更精準」等描述的測量方法。

- 來源：[Google](https://blog.google/products-and-platforms/products/search/gemini-4-hydrogen-search-upgrade/)

## Qwen3-1.7B 對話表徵的多語言幾何實驗

Operator_0x 以固定的 Qwen3-1.7B 建立互動圖譜，處理 100 個主題的英文、中文、德文與克羅埃西亞文問答，以及 90 個 Python 程式題。實驗從模型殘差流擷取 token 狀態，再以 PCA 將向量投影到三維；英文資料包含 900 個問答例，全部資料的 token 狀態則有 264,571 筆。

作者報告，在展示用的 Global PCA 三維投影中，英文 token 狀態的最佳平面約包含 99.3% 的該投影變異；檢查全部 final token states 時，顯示的三個 Global PCA 軸只保留 17.6% 的原始變異。以 conversation averages 重新計算的 Conversation PCA，前三個方向保留 80.1% 的對話平均向量變異。這些百分比的分母與資料點不同，不能互相當成同一項指標。

圖中不同語言的區域有重疊也有偏移，程式資料落在英文及其他拉丁字母資料的廣泛鄰近區域。作者明確指出，語言、文字系統、tokenization、措辭與回答品質在資料中同時改變，因此幾何圖形無法單獨拆出「語意」因素。資料也不是完整語料分布：生成使用 thinking off、greedy decoding 和 256 token 回答上限，德文與克羅埃西亞文目錄由協作者翻譯與審閱，程式碼輸出沒有執行或正確性測試。

- 來源：[Operator_0x](https://operator0x.com/field-notes/qwen-conversation-state-space/)

## RoPE 仍是主流，近期架構也出現部分旋轉與 NoPE 層

Sebastian Raschka 的教學整理 LLM 如何加入 token 的位置資訊，並以 PyTorch 實作 learned absolute embeddings、固定 sinusoidal encoding、RoPE 與 attention 中的相對位置 bias。RoPE 在 query 和 key 的特徵對上依 token 位置旋轉，使內積結果保留相對位置差；教學中的程式只對 query 與 key 旋轉，不對 value 旋轉。

文章比較其 LLM Architecture Gallery 中的模型，指出 2025 至 2026 的樣本仍以每個 softmax attention layer 都使用 RoPE 最常見，但混用 RoPE 與 NoPE 的模型增加；在使用 RoPE 的樣本中，partial RoPE 也更常出現。作者以 MiniMax-M3 為例：128 維 attention head 中使用 64 個 rotary dimensions，其餘維度不旋轉；這會減少預先計算的 cosine、sine 表大小，但不會減少 KV cache 儲存的完整 key 和 value 向量。

NoPE 指不使用明確 positional encoding，依靠 causal mask 提供部分位置訊號。文章列舉的 SmolLM3 在每四個 transformer block 中有一層跳過 RoPE，並引用其作者所稱的長上下文結果改善。這些是特定模型配置與文章整理的架構資料，不代表 NoPE 或 partial RoPE 在所有模型、長度與評測上都優於完整 RoPE；作者也指出其 2026 年 gallery 分組仍小，趨勢是否延續尚難判定。

- 來源：[Sebastian Raschka](https://magazine.sebastianraschka.com/p/understanding-positional-embeddings)

## OpenAI 解散獨立機器人團隊，將研究併入一般模型與 Applied 組織

Fortune 11 月 13 日報導，OpenAI 已解散獨立的 robotics team。OpenAI 向 Fortune 確認，機器人研究人員改隸主要研究團隊、向 Chief Research Officer Mark Chen 報告；應用機器人與硬體團隊則移到由總裁 Greg Brockman 負責的 Applied 組織。公司說這是為了加快機器人進展，而不是放棄機器人計畫，並表示仍在開發人形機器人，Sam Altman 曾將首次公開展示目標放在 2027 年。

Fortune 將重組與一項產業方向連結：使用處理語言、程式碼與視覺的一般模型，直接控制實體機器，而不為每種機器人建立獨立模型。報導引述 NVIDIA 的一項模擬操作 benchmark：由 GPT-6 Astra 驅動的 agent 成功率為 74.8%，該排行榜列出的最佳專用機器人模型為 51.0%。這是模擬機器人環境的結果，不是實體機器人部署數據。

報導也引述研究者指出，一般模型可能仍需要雲端連線且速度較慢；機器人公司則擁有在工廠等實際場所取得的部署資料。OpenAI 本次重組的理由、2027 展示是否如期，以及一般模型在真實機器人上的可靠度，均不由上述模擬 benchmark 或組織調整單獨證明。

- 來源：[Fortune](https://fortune.com/2026/11/13/openai-disbands-robotics-team-as-its-general-models-start-running-robots/)
