## 🔥 美國中期選舉：先看 AI 資料中心的電費與地方許可

CNBC 11 月 4 日美東凌晨 1:53 更新的選舉直播，已預測民主黨拿下國會兩院，並預測翻轉德州與俄亥俄州州長。這是媒體判定，不是所有選區的最後認證，也不代表新政策已在選舉夜生效。

對 AI 基建，具體的觀察點是新增供電、接網及電網升級由誰付錢。白宮3月已有用電戶保護承諾；H.R.9340眾院通過文本則對特定100MW以上負載提出增量成本與財務保障標準。眾院表決通過不等於法律已生效，州層級考量程序與個別合約也不能省略。

選後是否影響建廠時程與設備拉貨，仍要追正式許可、費率與公司公告，不能直接寫成AI投資停擺。本站另以官方文本拆解這條政策傳導路徑。

## 🔥 Anthropic 向 SEC 提交擬議 IPO 的 S-1

Anthropic 表示，Anthropic, PBC 已向美國證券交易委員會提交 Form S-1 登記聲明，計畫發行 Class A common stock。公司預計以「ANT」代號在 Nasdaq Global Select Market 掛牌，但目前尚未決定發行股數與價格區間。

這份文件仍是登記程序的一部分。Anthropic 的公告寫明，登記聲明尚未生效，在生效前不能出售證券或接受購買要約；公告本身也不是出售要約或招攬購買要約。投資人能取得的正式發行條件，仍要等後續 prospectus 與 SEC 程序。

公司公告沒有在這個頁面提供估值、募資規模或上市時程。Anthropic 的 PBC 身分與使命敘述也不等於已公開說明上市後的治理安排；目前可確認的是提交了登記文件，而不是已完成 IPO。

## Momentic 公布 AI QA agent 的 1,396 個缺陷測試

AI 測試平台 Momentic 在網站列出 QA Bench，讓 Mo、Codex、Claude Code 與 Devin 在 Gitea、Metabase、Twenty、Saleor 四個真實網路應用的 20 個區域中尋找標記過的缺陷。頁面說明每個區域提供 60 分鐘，Mo 約找到 269 個標記缺陷，下一名 agent 約找到 86 個。

Momentic 將測試定義為讓 agent 操作執行中的應用程式，並同時計算找到的缺陷是否為真。平台的 Mo 也能從 prompt 開始探索應用程式、留下錄影與重現步驟，另有 CLI、CI 整合與 MCP server，讓測試結果可加入 pull request 或部署前檢查。

這些數字是 Momentic 公布的自家 QA Bench 結果。頁面未在摘要中列出每個 agent 的完整提示、模型版本、工具權限、失敗案例分布與獨立重現結果；因此 269 對 86 只描述這組測試設定下的缺陷發現數，不能直接轉換成所有軟體專案的 QA 成功率。

- 來源：[momentic.ai](https://momentic.ai/)

## Cisco 將網路遙測與 OpenAI 模型接進資安調查流程

OpenAI 的客戶案例表示，Cisco 將網路遙測與 OpenAI 模型結合，用來關聯分散在微服務、容器與叢集的安全訊號。Cisco 的 Jeetu Patel 說，單獨看可能正常的兩個訊號，合併後可能顯示出需要調查的模式；案例也提到 Daybreak Defense Network 與 Cisco Cloud Control 的整合探索。

案例描述的處理範圍包括從調查到修補：Cisco 認為模型可協助縮短漏洞調查與回應時間，並把相關能力接到既有掃描工作流。對 agent 化環境，Patel 列出三項工作：防止惡意攻擊、偵測並攔截非預期行為，以及接近即時地運作。

這是 OpenAI 發布的企業客戶案例，文中主要使用 Cisco 主管的描述，沒有提供漏洞修補時間的基準值、誤報率、模型介入前後的對照數據，或第三方評測。文章提到的 zero data retention、客戶資料邊界與隔離，是 OpenAI 對企業部署條件的說明，不是這個案例對所有環境的獨立驗證結果。

- 來源：[openai.com](https://openai.com/index/cisco-cyber)

## 一篇實務文章把提示設計拆成程式設計習慣

Aaron Brethorst 在〈Prompting Is Programming〉中，將使用 LLM 時的工作拆成幾個與程式設計相似的步驟：先定義輸入與完成條件，把任務分成可檢查的小步驟，處理例外情況，並把錯誤輸出當成需要修正指令的訊號。

文章以一名非軟體背景的教授使用 Claude 的經驗為例，描述對話在沒有明確目標與輸出規格時反覆偏移。作者的主張是，工程師長期受到編譯器與測試回饋訓練，較習慣懷疑「看起來合理」的結果；其他領域使用者則可能需要另外建立指定與驗證的工作習慣。

這是作者根據個人觀察提出的解釋，不是生產力研究或跨職業比較。文章也承認領域知識仍影響使用結果，但把「知道什麼是正確答案」與「把任務指定到可執行」分成兩種能力；文中沒有提供足以估計兩者對工作成果各自影響的實驗數據。

- 來源：[brethorsting.com](https://www.brethorsting.com/blog/2026/11/prompting-is-programming/)
