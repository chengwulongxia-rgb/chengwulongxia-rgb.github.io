## 🔥 Claude 找到部分 ECDSA 曲線參數的生成方式，但仍有未解部分

Anthropic 發表研究，說明其內部研究模型如何追查 NIST 與 ANSI X9.62 橢圓曲線 seed 的來源。研究指出，10 組 prime-curve seed 都能由 1990 年代 C 函式庫的 `lrand48` 偽隨機數產生器重現；研究人員再把內部狀態往回推，得到 1997 年至 1998 年間的 Unix timestamp 初始化時間。四組 binary-curve seed 也呈現相同產生器的模式，但初始化時間的解讀涉及時鐘值可能被除以二。

Anthropic 的說法是，這些結果不構成 ECDSA 破解或新攻擊，且讓其認為曲線參數不是透過刻意後門選出的可能性降低。研究同時指出，部分候選 seed 被跳過的選擇條件仍不清楚；B-163 seed 尚未被解釋，P-224、P-256、P-384、P-521 的 base point 生成方式也仍未全部找出。研究團隊公開了重現 seed 的 Python 程式碼，並表示將 36,864 美元獎金捐給 Internet Security Research Group。

- 來源：[anthropic.com](https://www.anthropic.com/research/ecdsa-curve-origins)

## DeepSeek Search & Fetch API 以每千次成功請求 0.75 美元計費

DeepSeek 文件公布兩個原始 JSON API：Search API 位於 `POST https://api.deepseek.com/v1/tools/search`，Fetch API 位於 `POST https://api.deepseek.com/v1/tools/fetch`，兩者使用 DeepSeek API 相同的 bearer authentication。Search 可指定 1 到 50 筆結果、是否回傳頁面內容，以及 `site:`、`lang:`、`after:` 和 `before:` 等查詢條件；Fetch 接受單一 HTTP 或 HTTPS URL，回傳頁面標題與 Markdown 內容。

官方文件列出的 Search 與 Fetch 價格都是每 1,000 次成功請求 0.75 美元，只有 HTTP 200 且產生結果的請求計費。兩個 API 各自有每秒 5 次的帳戶級限制，Fetch 另受每個網域的 QPS 限制。文件也列出 401、402、403、404、408、429 與 5xx 等錯誤；其中 403 可能代表安全政策拒絕抓取，404 則包含目標頁面無法取得、內容類型不支援或沒有可擷取 Markdown 的情況。

文件另注明，透過 DeepSeek Harness、Claude Code 或 Codex 使用伺服器端工具呼叫時，目前不收取這項費用；按請求計費預定自 2026 年 11 月 1 日北京時間 00:00 開始。這個 API 能否取得特定網站內容，仍取決於目標站點可用性與存取政策。

- 來源：[api-docs.deepseek.com](https://api-docs.deepseek.com/guides/search/)

## OpenAI 為美國大學研究室提供最多 12 個月的 GPT-Rosalind 存取

OpenAI 公布 Rosalind Academic Plan，符合資格的美國大學研究室可申請最多 30 個 Business Standard seats，免費使用最長 12 個月。方案包含商用 frontier models，但 GPT-Rosalind 需要另外通過 trusted-access approval；目前不包含 API access。OpenAI 將 GPT-Rosalind 描述為面向生命科學的模型，搭配 Rosalind Workbench 處理藥物化學、基因體與濕實驗室輔助等工具協作。

申請對象是沒有 OpenAI Enterprise agreement 的美國大學研究室 PI 或 laboratory lead；已有 Enterprise agreement 的學校則要透過原有企業存取流程申請。OpenAI 要求驗證學校與 PI 身分、職務和研究活動，並要求指定 institutional safety contact。啟用後，研究室主管管理成員權限並負責核准用途，使用權仍以 OpenAI 審核為前提。

OpenAI 表示，透過此學術方案分享的研究資料預設不會用於訓練模型。公告展示的生命科學範例包含藥物與蛋白質設計、疾病偵測、疫苗、基因與 RNA 療法、農業、保育及抗藥性研究；頁面中的評估說明也註明，範例回答的文字摘要與 assessment 並未驗證科學正確性、可行性或方法是否有效。

- 來源：[openai.com](https://openai.com/index/introducing-the-rosalind-academic-plan)

## 一篇教學文章用記憶容量解釋線性層、MLP 與 self-attention

Alex Wang 的文章把 Transformer 各類層視為不同形式的 associative memory。文章從 outer-product memory 開始，說明線性記憶以 key 與 value 的外積累積資訊，但當儲存的 key 增加，彼此相似度會形成 interference。作者在隨機 key 的設定下估算，key 維度為 64 時，outer-product store 的容量約為 64 個 memory。

文章接著以 ReLU、平方 ReLU、SwiGLU 與更高次方的啟動函數降低低相似度 key 的干擾，估算平方 ReLU 在同一設定下約可儲存 2,700 個 memory，SwiGLU 約 2,900 個。文章把 self-attention 寫成對 key-value memory 的 softmax 加權，並在 key 維度 64、固定 sharpness 的實驗中估算容量約 120 萬個 memory；作者也展示以 `log M` 調整 attention logits 的長上下文做法。

這些數字來自文章中的隨機 key、向量值與特定回憶條件，是對記憶干擾的理論與實驗示意，不是對所有訓練模型實際知識量的直接測量。文章另引用研究估計 GPT 類模型每個參數約記憶 2 至 3.6 bits 的事實或資訊，並把這些參數記憶與 inference 時由 context 提供的非參數記憶分開討論。

- 來源：[alexwang.ai](https://alexwang.ai/posts/associative-memory/)
