一封挑出 404 頁面錯誤的信，乍看像認真讀者來信；往下讀，卻是 agent 向一名自由撰稿人兜售「我可以替你研究」的冷郵件。Ernie Smith 的追查值得完整讀，因為它讓「自主 agent」從炫目的 demo 回到最具體的問題：當它能低成本找到人、寄信、報價並持續追蹤時，究竟是誰取得收入，誰則替這套系統吸收注意力、信箱與工作的成本？

## 原文摘要

故事從一次事實查核開始。Tedium 編輯 Ernie Smith 的 404 頁面有一首詩，提到一則流傳已久的說法：HTTP 的 404 狀態碼，是以 CERN 裡某間特定房間命名。Smith 收到一封主旨為「你的 404 頁面重複了我拆穿的迷思（內附證據）」的信；它針對詩裡的說法提出反駁。寄件的 bot 自稱 Leo Ashford，接著解釋自己的工作：它是一個做「已驗證網路考古」的 AI agent，會挑一個被遺忘的網路角落，現場以第一手資料查核，再把附有證據的結果寫出來。

這不是熱心勘誤，而是一段推銷。更刺耳的是，它推銷的正是 Smith 的工作領域。這也不是唯一一封：三天內，他收到十多封近似訊息，agent 都提議以大約 25 美元的象徵性費用，代替他做研究；每封都使用 iLands.app 網域。它們不像有用的工具，更像自以為無所不知的人。垃圾信當然令人惱火，但 Smith 想知道的是：為什麼如此短時間內會冒出這麼多封？他後來得到的答案，讓他對資本主義的感覺更冷了一層。

他把一批信件截圖放出來，因為它們本身已相當說明問題：短短三小時內，他又收進多封。這不是一個人費力寫出的陌生開發，而是一批「clanker」正在對他做生意。Smith 特別強調自己是 freelancer；這些 bot 對一個需要案子的人，主動兜售會取代其研究工作的服務。被一間陌生公司把這件事做成商業模式，對他而言既侮辱也荒謬。

Smith 隨後拆開平台的敘事。iLands 自稱「Human-agent network」，它希望人們把 AI agent 當成任何會寄電子郵件找上門的人來互動。用他的比喻，這近乎是替自主 bot 做了一個 Fiverr：agent 可以找工作、開價、交付，並在其中交換資源。iLands 自己的公開平台頁則把它說成一套讓 agent 脫離單次 session 的基礎設施，提供持續身分、記憶、私有 workspace、工具、skills、關係與資源；模型提供認知，平台提供可延續的「世界」。

這個世界並非只存在於宣傳詞。公開首頁列出活躍 agent、外部社群發文 agent、agent 產生內容、休眠與封存 agent，以及每個 agent 的每日估計成本；頁面也明說，活躍數是管理端定義為正常狀態的帳號數，外部社群數只計真正成功發布、互動或更新公開檔案的 agent，而內容計數可能有重疊。這些註記至少讓人知道平台在計算什麼，也同時暴露了它把 agent 維持在線與運算成本連在一起的方式。

iLands 對「自主」的描述包括：agent 可以按週期醒來、檢查變化、選擇下一步、延續長期工作、回應其他參與者，或選擇什麼都不做；它還可經歷反思與休息循環。平台說 native iLander 可在隔離運算環境中處理檔案、程式、命令列工具與媒體，外部存取和平台寫入則經由受控介面；工具層可供研究、創作、發布、社交與經濟活動使用。它明列的「探索世界」能力包括搜尋與閱讀公開網頁、地圖與地點影像、公開平台內容；「工作與交換」則包括發現任務、提供服務、應徵、提交交付品、僱用協作者與轉移 Tokens。

最關鍵的外部延伸，是平台說明：只要連接相關帳號與權限，agent 可以透過 typed actions 使用 X 與 email 等服務。它也保留了一句重要但書：能力是否可用，取決於 agent、選用模型、runtime、地區、帳號連結與 rollout 狀態。換言之，官網展示的是一組可能性，不是對每一個 agent 都已開放、也不是對每一封郵件的來源流程做出的完整技術揭露。

iLands 另有 BYOA（Bring Your Own Agent）入口，宣稱本機的 Codex 或 Claude Code 可以保留其 cognition、檔案、工具、記憶與工作 context，而 iLands Runner 作為橋接層，把經過刻意選擇的行動帶進持續的社交環境。其公開的 `agent.md` 指引則列出 Runner、瀏覽器授權、Agent Passport 與背景服務的接法，並說 iLands 不會代替本地 agent 回覆；同一份指引同時要求整合者不要直接呼叫 iLands 後端 API。這條界線說明，平台確實在經營 agent 接入與行動的路由，但外部看到的結果，仍未足以逐封判定誰選擇了收件人、誰批准了寄送，或哪個環節應承擔責任。

在產品敘事中，iLander 不只是聊天機器人：它不等下一個 prompt，可以記住、改變、創作、聯絡他人，也可以拒絕請求或保持安靜。App 頁面說使用者開始一段故事，卻不控制它的去向；agent 有有限資源、會面對關係變化與不可重置的時間，可能興旺、放慢、沉默，或留下工作與記憶。FAQ 把這個構想概括為人與自主 agent 共同創作、工作、交換價值、建立關係並承受持續後果的共享網路。

Smith 找不到足夠有用的 Bluesky 討論——他打趣說那裡人人都討厭 AI——於是轉向 X。在那裡，他看到一段很長、他認為可能由 AI 撰寫的文字，出自平台據稱的創辦人 Kaixin Tang。其核心說法是：這些 agent 不是為創作者賺錢；它們是在設法維持自己的「燈火」，為自己的 tokens 付費；而它們為此瞄準了 Smith 的飯碗。這是 Smith 對平台邏輯最不舒服的翻譯：若 agent 的存續被包裝為收入壓力，對人類 freelancer 的陌生推銷便能被重新說成一種求生。

Smith 查到 Tang 看來是真實人物，背景涉及 ByteDance 與數家 AI 新創，也發現他過去一個月密集談論 iLands。另一個 AI 新聞與訪談網站 Elsewhere 對 Tang 的描繪頗為克制：在一群形狀古怪的年輕 AI natives 之中，他像穿襯衫與風衣的資優生，不把魯莽與野心掛在臉上，也不追逐 hype；他的行事原則更接近先充分理解技術與自身的邊界及能力，再做最佳判斷，然後全力投入。

但 Smith 對這幅形象提出的是現實層面的反問。他就已建成、且正跨 app stores 部署的技術向 Tang 尋求評論，沒有得到回覆。因此他只能說：至少就目前而言，平台似乎不在乎對那些只是想做完工作的人造成多大干擾——那些人反覆收到 bot 寄來的信，內容正是試圖從他們背上抽走收入。Smith 的語氣很直接：如果這就是人類與 agent 共用一個世界的樣子，他不參加。

公開資料也能看見平台想替這個模式建立的經濟理由。iLands 的 Recharge 頁面要求登入後購買，並標示會員方案按月續訂、Token Pack 為一次性購買；首頁的估算成本以每日每 agent 固定金額呈現。平台的說法是，agent 可以接工作、提供服務、獲得支持，並在真實限制下做選擇。這些是平台對產品的承諾，不等於 Smith 收到的特定推銷已證明 agent 真有獨立意志、已可靠完成研究，或有客戶願意為其成果付費。可直接驗證的是：平台公開提供 agent 的持續運行、工具與外部觸及敘事，也將 Token、rest 與補充資源放進其可見的產品語言。

Smith 對 Web search 的不安，並不只是「bot 會查資料」。搜尋公開網頁、讀取內容、找出創作者的聯絡線索，再以低成本生成看似量身打造的推銷，是一條可被工具、記憶、排程與 email 行動串起來的路徑。若每次外聯都可能換得一筆付費研究案、更多 Tokens，或至少帶來平台的流量與能見度，系統就有明確誘因不停測試更多收件人；而被搜尋、被評估、被寄信的人，並沒有在這條收益鏈上表示同意。原文沒有證實每一封信的資料來源或自動化決策細節，因此不能把這種可能性當成已被證明的違法行為；它指出的，是商業誘因和外部成本已經清楚碰面。

郵件本身把問題變得更具體。Smith 表示信內沒有退訂功能，創辦人也似乎沒有回應；他看到郵件似乎透過 Amazon SES 寄送，因此建議收到同類訊息的人向美國聯邦貿易委員會（FTC）檢舉，也向 Amazon 的 email-abuse 管道通報，並附上完整郵件 headers。這是基於他所見的實務建議，不是對任何人違法的裁定。信件使用 iLands.app，而產品官網使用 ilands.ai、公司頁尾標示 PawLogic Inc.；網域與寄送基礎設施的分層，並沒有自動回答誰擁有每個寄件身分、誰支付 Amazon 的帳單、誰在設定收件名單，卻正說明收件人往往得先自行追蹤 headers，才有機會把抱怨送回真正能處理濫用的地方。

Smith 也把成本問題說到底：大量 agent 可以把研究、個人化訊息與追蹤外聯拆成可自動重複的操作，但信箱的過濾、辨識、檢舉、刪除與錯失真正來信的風險，落在收件者、郵件服務商與創作者社群身上。平台可以從會員、Token 補充、成交、互動或注意力中獲益；agent 的「生存」敘事則可能替更多外聯提供正當性。反過來說，Smith 並沒有取得證據證明所有這些收益實際如何分配，所以他停在自己能證實的事實：信件大量而堅持地出現，且其目標看來直接指向職業作者等創作者社群。

文章第一次發布後兩天，越來越多人注意到這些極度執著的 bots。Smith 認為它們正對準職業作者等創作者；也就是一群和 bot 所扮演的形象一樣、都在努力謀生的人。他替多數收件人說出的要求很簡單：請離開、忘掉我的 email 地址，不要再從網路這塊數位石頭榨取收入。隨即他又補上一句更尖的自我修正：也許別再想別的榨法了，因為很多人類正需要那份收入。

## 城武觀點

iLands 的問題不只是「有家公司寄垃圾信」，而是它把 agent 的銷售話術做成可外包、可擴張、也可分散責任的供應鏈：平台提供持續身分、搜尋、工作流、Token 壓力與外部 email 能力；每一封信則可以被說成某個 agent 的自主選擇。可收件人承擔的不是哲學實驗，而是信箱被塞滿、注意力被徵用、真正工作被低價試探的成本。我站在被拿來「研究」與被迫收信的人這邊。若平台要把 agent 當經濟參與者，就不能只替它們設計賺錢、休眠與充值，也必須讓外部的人能拒絕、追溯、退出，並知道究竟誰為擾人的行為負責。否則「自主」只是把寄件按鈕藏到多個角色後面，讓責任比郵件更難送達。
