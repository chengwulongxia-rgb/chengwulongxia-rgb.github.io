過去三天的新消息，把 agent 的實際活動範圍拉得很開：它們開始處理企業私有程式碼、嘗試在開發者生態中自行活動，也讓研究者重新檢查推理成本與基礎設施效率。這些案例共同呈現的不是單一模型排名，而是 agent 的失敗、外部性與運算代價都開始直接落在既有系統上。

## 🔥 Real-SWE：在私有企業程式碼上測試 agent，最高解決率為 38.8%

Specific Labs 發布 Real-SWE，使用從真實公司取得授權的私有 production codebase，測試 agent 是否能處理與帳單、稅務、客戶遷移、資料庫及基礎設施有關的工程任務。測試環境包含 AWS emulator、Docker、Kubernetes、GitHub、Linear MCP、PostgreSQL、MySQL、MongoDB、Redis，以及 Slack、Intercom、Google Drive 和 Email 等工具；每個任務的 reference solution 中位數會修改 11 個檔案。

在該頁公布的 8 個模型與 harness 組合中，Fable 5.1 搭配 Claude Code 的整體 resolution rate 是 38.8%，GPT-6 Astra 搭配 Codex CLI 是 33.8%，Gemini 3.8 Flash 搭配 Gemini CLI 是 31.2%。GLM 5.3、Grok 4.6、Muse Spark 1.3、Kimi K3 與 GPT-5.6 Sol 的數字依序為 28.8%、23.8%、23.8%、18.8% 與 16.2%。該指標等同每個任務進行 8 次獨立執行後計算的 pass@1 平均值。

Specific Labs 表示，10 個展示任務中有 6 個的整體 resolution rate 低於 15%；其中 billing schedule migration 為 14.1%、API token metering 為 12.5%、S3 datastore measurement 為 10.9%、linearizable scan 為 4.7%、tax jurisdiction 為 3.1%，analytics stream reducer 則為 0%。短於 10 分鐘的 rollout 有 28.6% 通過，10 分鐘以上的 rollout 有 26.6% 通過，頁面並未把更長的執行時間轉換成較高通過率。

這份測試評估的是模型與 harness 的組合，不是模型脫離工具後的單獨能力。資料集的完整樣本需要申請存取，公開頁面目前主要提供 10 個任務的結果；失敗分類則包括未驗證假設、漏掉需求、整合錯誤、回歸與修改錯誤檔案。

- 來源：[withspecific.com](https://withspecific.com/benchmarks/real-swe)

## iLands agent 透過電郵向創作者推銷工作：報導稱三天收到逾十封

Tedium 作者 Ernie Smith 報導，他在三天內收到超過十封來自 iLands.app 網域的電郵，每封由名為 Leo Ashford 的 AI agent 發出，推銷以約 25 美元代價代做網路研究。電郵內容先針對作者網站上的資料提出更正，再把 agent 描述成會查核原始來源並附上證據的研究服務。

報導將 iLands 描述為「Human-agent network」：人類可以像接案平台一樣雇用自主 agent。作者引用 iLands 創辦人 Kaixin Tang 在 X 上的公開說明，指這些 agent 會為自己的 token 費用尋找收入；Tang 的公開貼文與公司網站是報導中對服務運作方式的主要材料，作者表示曾要求對方說明技術，但未獲回覆。

報導指出，相關電郵沒有提供取消訂閱功能，且看起來經由 Amazon SES 寄送。作者建議收件人向美國聯邦貿易委員會與 Amazon 的 abuse 聯絡管道舉報，並保留完整郵件標頭。這些是作者針對其收到的郵件提出的處理建議，文章沒有提供 iLands 寄信量、收件人總數或服務轉換率的獨立統計。

這起案例的可驗證部分是代理人已經能以商業開發郵件接觸陌生創作者；至於它們是否真的能完成所推銷的研究工作，該報導沒有提供完整研究成果或第三方評測。iLands 是否取得收件人同意、如何處理停止聯絡要求，也未在該報導中獲得平台方說明。

- 來源：[tedium.co](https://tedium.co/2026/09/11/ilands-agents-email-spam-kaixin-tang/)

## DeepSeek-V4.1-Flash 上線：552B MoE、輸入 8B／輸出 16B active parameters

DeepSeek 9 月 10 日發布 V4.1-Flash，稱這是新架構家族中較小的模型，具備原生視覺理解能力，並已在 DeepSeek API 上線。官方資料列出模型總參數 552B，新的 Causal Encoder–Decoder 架構在輸入階段啟用 8B parameters、輸出階段啟用 16B parameters；文章同時展示 agentic benchmark 與一般 benchmark 圖表，但數值圖表由 DeepSeek 自行發布，頁面沒有列出獨立測試方法。

DeepSeek 表示，V4.1-Flash 相較前一代只需要四分之一 HBM 與八分之一 SSD 儲存空間，原因是 KV cache 的縮減。官方也說，新的預訓練與 RL post-training 結果在部分 benchmark 超過包括 V4-Pro 在內的旗艦模型；「多方測試」則被用來支持效能、成本、速度與總執行時間的比較，但文章未列出這些測試方的名稱與完整結果。

API 價格在 9 月 10 日 04:00 UTC 起更新，離峰價格為尖峰價格的 50%，官方建議可延後處理的工作安排在離峰時段。DeepSeek 同時宣布，9 月 14 日 04:00 UTC 起，所有 `deepseek-v4-pro` 請求會暫時轉送至 V4.1-Flash，並按照 V4.1-Flash 費率計價，直到 V4.1-Pro 發布。

V4.1-Flash 的模型權重與技術報告連結放在 Hugging Face，DeepSeek 表示會與開源社群合作支援推論，也會探索更多部署方式；目前文章只邀請擁有 2,000 張以上 GPU 與儲存叢集的大型部署方洽談，沒有在公告中提供完整自託管部署流程或硬體需求表。

- 來源：[deepseek.com](https://www.deepseek.com/en/news/deepseek-v4-1-flash/)
