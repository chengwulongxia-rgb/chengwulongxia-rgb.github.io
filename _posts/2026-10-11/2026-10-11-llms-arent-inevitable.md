「AI 不可避免」經常被拿來終止爭論：既然技術遲早會留下來，人們最好立刻接受它。Iris Meredith 不只反駁這句話，而是先替「技術必然性」訂出可檢驗的條件，再以火器、羅盤與化學武器為對照，逐項判斷 LLM 是否真的強到讓拒絕採用者無法生存。

## 原文摘要

### 「必然」不能只靠事後回看

作者指出，「AI 只是工具」與「AI 不可避免」幾乎同樣常見。後一句通常暗示：這項技術一定會長久存在，人類也一定會把思考交給機器，因此抵抗沒有意義。她認為這是一句用來停止思考的陳腔濫調，但正因為它被反覆使用，才值得把錯誤拆得更仔細。

在技術真正出現以前，沒有人能確定它能否被開發、能否運作，更不可能保證社會會採用它。例如，可實用的核融合發電至今仍不能被宣稱為「必然」。反過來看，一項技術一旦普及，人們又很容易倒推它原本就注定出現；但說 iPhone 的誕生不可避免，並沒有提供多少資訊。我們最多只能說，某種大致相似的行動運算裝置可能會出現，至於它最後採取什麼形態，本來就有許多其他可能。

因此，問題不能停在「技術是否存在」，而應該問：AI 支持者所說的「必然」究竟是哪一種必然？如果意思是拒絕 LLM 的個人、組織或社會終將落後，甚至被採用者支配，那麼這個命題就需要更嚴格的標準。

### 技術必然性的四項條件

作者先拒絕一個太輕巧的答案：宣稱所有技術都受歷史偶然左右，在哲學上或許沒錯，卻不能解釋為什麼某些技術確實會迫使對手採用。火器就是典型例子。火器一旦成熟，一個社會若想維持安全與獨立，就得自己使用，或讓別人代為使用；其他選項很快會失效。

但必然性從來不只存在於器物本身，也取決於地理、制度與文化。中美洲文明知道輪子，也製作過帶輪玩具；只是在茂密叢林中，又缺乏既有道路網，輪式運輸並沒有壓倒性的實用價值，因此水運與馱獸更適合當地條件。技術已被理解，不代表它就必須成為社會基礎設施。

大砲的價值也會隨環境改變。政治分裂的歐洲遍布為抵抗攀牆攻城而建的高而薄城牆，大砲能比舊式攻城器械更快轟出缺口。中國常見的城牆則以夯土為主體、外覆石材，厚重結構更能吸收砲擊；大砲最後仍可能打穿，卻不會同樣迅速。相同火器進入不同防禦傳統，帶來的戰略壓力並不相等。

依此，作者提出四項必須同時成立的條件：

1. 新技術完成某項工作時，品質至少要與替代技術相當，不能明顯較差。
2. 那項工作必須具有社會價值：社會需要大量完成它，而且現有勞動力在某種意義上是稀缺的。
3. 新技術必須在合格產出的數量或品質上，以壓倒性幅度超越替代方案。普通程度的改良不足以構成必然性，差距必須大到足以改變力量平衡。
4. 不採用者不能只靠相對低成本的行為調整，就中和新技術帶來的優勢。若對手可以稍微改變做法便削弱其效果，採用仍是選擇，不是生存條件。

少掉任何一項，普及都仍屬於偶然且可選的歷史路徑。真正「必然」的技術，是不採用者會迅速被採用者壓倒，乃至被吞併或控制的技術。作者認為，這也最接近 LLM 擁護者實際使用「不可避免」一詞時的意思。

### 火器為何接近必然，羅盤為何不是

火藥武器符合上述模式。大砲比配重式投石機更快、更有效率地破壞幕牆；在中世紀政治割據的歐洲，縮短圍城時間具有極高價值。大砲對既有攻城器械形成壓倒性優勢，早期輕兵器單發釋放的能量也遠超同級弩或長弓。更重要的是，火器很難用便宜方法抵銷：個人護甲難以有效防禦，能抵抗砲擊的新式堡壘又需要龐大的勞力、財政與社會重組。大砲進入歐洲後，軍隊若不快速採用，就可能被更早採用的國家吸收。

磁羅盤則只滿足部分條件。它找北方比觀測太陽後計算方便，沒有已知地標時也能使用；對需要遠洋航行的海權國家而言，方向資訊當然重要。然而，羅盤並沒有讓其他導航方法完全失效，人們仍可在沒有它的情況下有效航行；一個國家也能藉由不投入海洋競爭、轉向陸權發展，降低對羅盤的依賴。歐洲殖民強權確實靠羅盤擴張航程並攫取遠方資源，但俄羅斯即使沒有它，很可能仍會成為歐陸強權。羅盤很有用，也很強大，卻不像火器那樣迫使所有重要行動者採用。

### 將 LLM 放進四項標準

第一項是品質：LLM 能否做到不明顯遜於人類？作者承認這一點有爭議。她判斷，目前 LLM 做不到人類最高水準，甚至做不到良好的人類水準，並進一步認為它可能永遠做不到。不過，多數日常工作本來就不是以良好標準完成；大量知識工作只有平庸品質，有些甚至非常糟。在那些環境裡，人類產出與 LLM 產出確實可能近乎可互換。因此，LLM 大致通過第一項，但這個通過建立在現實世界充斥低品質工作之上。

第二項是社會價值。軟體開發、研究、平面設計等工作都具有價值，人才也可能稀缺；問題是，作者認為 LLM 通常只能取代其中價值最低的部分。它可以大量產出勉強可接受的平庸程式碼，卻只能做出最差一級的平面設計與相當表面的研究文件。一旦任務真的要求品質，人類專業仍不可缺少，不論流程中是否使用 LLM。於是第二項只有混合結果：LLM 的確能做一部分有社會意義的工作，但工作的社會重要性越高，它能代替的部分反而越少。

第三項才是能否形成必然性的核心：LLM 帶來的差距是否大到足以壓倒不用它的人？作者的答案很明確：沒有。頂尖工作仍依賴未經 LLM 增強的人類；即使是要求較低的任務，使用者也得投入時間下指令、校正方向、檢查產出是否可用，所以產量並不會無限制增加。

作者以 PowerBI 儀表板作為帶有限定語的假設：某些工作流程導入 LLM 後，產量或許能提高約 20% 到 50%，但這不是實測定律，也不代表整家公司生產力同幅成長。儀表板很可能根本不是企業的核心瓶頸；就目前觀察，工作越接近真正限制營運的瓶頸，效率增益似乎越小。這個例子意在區分「局部多做一些」與「形成無法抗衡的能力差距」，不能被讀成作者宣稱 LLM 已普遍帶來 20% 至 50% 的生產力提升。

如果 LLM 真有壓倒性能力，作者認為市場早該出現至少一家科技公司，以競爭者五到十倍的速度推出新產品，並逐步把其他公司趕出市場。她的判斷是，這並未發生；反而是最激進押注 AI 的公司，往往比其他公司更掙扎。她用刻意誇張的軍事比喻說，足以證明技術必然性的效果，應該像戰車高速穿越阿登森林那樣明顯，而不是只能從零散的小幅改善中推測。

第四項是中和手段：不用 LLM 的人，能否以相對低廉的方法削弱它的效果？作者承認，社會趨勢需要時間發展，現階段證據仍有限；但她傾向認為答案是可以。社會對 LLM 使用，以及把生成垃圾偽裝成人類作品的行為，已出現強烈厭惡。新技術通常需要某種程度的社會接受才能普及；社會可能在冷漠或輕微反感下採用技術，卻很少在如此熾烈的敵意下照常完成普及。這種污名、拒用與品質辨識，可成為中和 LLM 優勢的一部分。

而且，這不是 John Henry 與蒸汽鑽孔機那種人力在純產能上注定落敗的情境。若只比輸出總量，LLM 當然占優；若只計算真正有用的產出，作者認為人類仍能輕鬆匹敵。綜合四項標準，她判斷 LLM 充其量只不完整地通過第一項；在真正把「有用」推成「必然」的第三、第四項，幾乎完全不及格。LLM 的用途可以是真實的，但它仍屬於偶然採用，而非所有人終將被迫接受的技術。

### 為何不必然的技術仍讓人感到無法逃避

這個結論沒有否認 LLM 正在大規模影響社會。相反地，作者接著追問：如果它沒有通過必然性測試，為什麼這麼多人仍感到自己無法拒絕？她以現代軍事中的化學武器作為類比。

Bret Devereaux 在〈Why don't we use chemical weapons any more?〉討論過一個反常現象：第一次世界大戰之後，頂尖軍隊幾乎不在戰場上使用化學武器。Sarin、VX、Novichok 等神經毒劑變得更致命，蘇聯與納粹德國在二戰中即使陷入極端困境也沒有動用；韓戰與越戰沒有以化學武器進行主要作戰，雖然越戰使用了表面上相似的落葉劑。俄烏戰爭也有俄軍使用化學武器的報告，但作者表示，幾乎看不到它被大規模運用並促成戰場進展的證據。

依 Devereaux 的解釋，致命性不等於軍事效用。現代機動戰依賴攻方快速移動，藉此孤立、擾亂守軍，使其無法組織協同防禦並最終崩潰。化學彈藥卻會讓大片區域對敵我雙方都難以通行，正好妨礙攻方最需要的機動性。完整防護也相對便宜：防毒面具加核生化防護服的成本，以現代經濟標準衡量可能低於一把步槍；富裕國家若願意，甚至有能力為全體人口提供防護。

此外，在真實戰場條件下，現代炸藥按重量計算可能比多數化學毒劑更致命。毒劑的理論致死劑量很低，但要讓目標確實吸入足量毒劑充滿不確定性。作者援引東京地鐵沙林事件：那是一個極有利於化學攻擊的密閉環境，約五公升沙林最終造成十二人死亡。這當然仍是嚴重暴行，卻也說明「物質極毒」不能直接推成「戰場效率極高」。對具備現代機動戰能力的軍隊而言，無論對手同樣現代化，或採用較靜態的作戰體系，化學武器都可能沒有多少用處。

但弱勢行動者對抗另一個弱勢行動者時，條件會改變。雙方若缺乏機動戰能力、全面防護與高效常規火力，化學武器仍可能實用；兩伊戰爭就是作者列出的反例。它也可能用於恐怖攻擊或傳遞政治訊號，例如倫敦的 Sergei Skripal 中毒案。這些案例並未證明先進軍隊終將普遍採用化武，反而說明它的用途高度依賴行動者所處的能力層級與文化情境：使用者往往是缺乏預算、意願或技能，無法執行現代機動戰的一方。

化學武器也揭示兩種常被混淆的「必然」。一項技術被發明後很難從知識中徹底刪除，因此它可能必然繼續存在；但存在不等於先進行動者必然生產、部署並日常使用。不能取消發明，與不能拒絕採用，是兩個完全不同的命題。

### LLM 與化學武器：作者的強弱行動者論

作者的核心主張是，LLM 在必然性上更接近化學武器，而不是火器。兩者都能完成一些工作，偶爾也比傳統方案有效；但它們沒有全面形成壓倒性優勢，有時甚至明顯更差，而且效果可能被相對容易地中和。

依她的推測，能力較弱的行動者互相競爭時，仍會長期使用 LLM。二、三流軟體公司可能持續依賴 hyperscaler 提供的模型或本地模型，因為它們首要追求的是大量交付品質低落的產品，功能是否可靠只是次要問題。她尖銳地以 Shopify 與 Mailchimp 為例，稱兩者在 LLM 普及前就已是勉強可用、卻仍能在各自市場較低階區段保持競爭力的產品。這些評語是作者對產品與市場的判斷，而不是本文另外提出的實證結論。

對「認真」追求專業成果的人與公司，作者則預測 LLM 的使用會少得多，甚至完全不用。她觀察到，自己認為嚴謹的使用者即使重度使用 LLM，使用模式也與一般用法不同，總量通常更低。若化學武器的模式可以類推，這些強勢行動者最後會大幅超越大量依賴 LLM 的競爭者。

她同時保留一個令人不安的例外：LLM 或許不擅長完成有實質內容的工作，卻可能在混合戰與干擾環境中有效，就像化武可被當作恐怖武器。LLM 支援的網路攻擊與人造草根輿論機器人，正是作者真正擔憂的用途。它們不需要產出頂尖成果，只需降低攻擊成本、擴大垃圾資訊數量，便能對社會造成影響。

因此，LLM 在弱意義上可以說是必然的：技術無法被「取消發明」，總會有弱勢行動者繼續使用。但在強意義上，作者斷然否定它的必然性。她判斷，任何真正重視專業進展的行動者，遲早會抵達一個臨界點：LLM 不再提供幫助，反而阻礙進一步提升。現實中也尚未出現足以迫使所有人採用的巨大能力優勢。

### 不能取消技術，但可以中和它的外部成本

未來會變成什麼樣，取決於社會能否中和 LLM 帶來的傷害。若無法透過制度或行為降低傷害，LLM 即使不具技術必然性，也可能因一連串偶然誘因而持續擴張。社會中的多數競爭，本來就不是頂尖強者之間的對決，而是能力有限的行動者互相競爭；若 LLM 的負面效果無法被中和，它仍可成為牽制更強對手的工具。

那將是一個相當黯淡的局面：真正的技能與用心仍有生存空間，但一部分人會不斷拿 LLM 互相轟炸，在過程中削弱自己的思考能力；所有人則共同承擔資訊水井被污染的代價，把原本可用於其他工作的時間耗在辨識、過濾與清理生成垃圾上。技術沒有壓倒人類，卻把外部成本散給整個社會。

另一條路是透過監管、經濟誘因與社會厭惡的組合，降低 LLM 對非使用者造成的影響，尤其是減少他人被迫承擔的過濾負擔。若能做到，作者認為不依賴 LLM 的人很可能直接在競爭中勝出。依她的判斷，LLM 目前主要幫助的是原本不擅長工作的人，讓較弱行動者暫時不至於被熟練從業者完全甩開。

這種平衡之所以暫時維持，一部分來自社會仍相信 LLM 強大而全能。有人相信它能把人做的所有事情做得更好，也有人期待巨幅生產力提升；作者認為，這些信念雖符合許多人的利益，卻缺乏理性基礎，而且已經開始侵蝕。一旦信念衰退到足夠程度，那些原本就以能力勝過 LLM、因而選擇不用的人，將突然取得決定性的競爭優勢。她不知道這需要幾年，或是否長達十年，但判斷這套信念終究很可能崩塌。

全文最後把「技術會一直存在」與「所有人現在都非用不可」再次分開。LLM 不會消失，人造草根輿論機器人也不會消失；但它是否強大到每個人都必須立刻採用，否則就會被採用者控制？作者的答案只有一個字：不。

### Arca 利益揭露

文章結尾附有作者自身的商業利益揭露。Arca 是 Meredith 推動中的付費專案，目標正是協助使用者維持足以超越 LLM 使用者的技能與知識；目前仍在非常早期的 early access 階段。它結合線上課程、期刊式內容與論壇，提供統計、工程基礎的專家筆記、配套練習，以及卡關時直接向作者提問的管道。

換句話說，本文不只是抽象技術評論，也與作者正在建立的產品敘事一致。作者明確邀請認同其主張的讀者註冊 Arca，以協助她完成專案，並直白表示這份收入也用來支應自己的生活。這項揭露不自動推翻文章論證，但讀者在評估她對 LLM、專業技能與「強弱行動者」的判斷時，應知道她同時是相關產品的經營者與受益者。
