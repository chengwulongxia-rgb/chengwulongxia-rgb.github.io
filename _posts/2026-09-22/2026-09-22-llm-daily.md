過去三天的素材集中在代理執行環境、可自行部署的小型決策模型，以及模型行為如何受到語言與訓練影響。這些項目的公開資料都能確認具體架構或研究方法，但對規模、泛化能力與使用者影響的描述，仍需和發布方的說法分開看待。

## 🔥 Google 開源 AX，將代理任務拆成隔離、工作區、網路與模型設定

Google 的 AX 專案提供一套以宣告式設定管理 agent 執行的控制平面，GitHub 專案採 Apache 2.0 授權。網站列出的四個核心抽象是 Task、Workspace、Gateway 與 Model：Task 用於執行代理程式，Workspace 宣告 Git repository、MCP server 與 skills，Gateway 管理網路允許清單與憑證注入，Model 集中設定模型、參數與 secrets。

展示流程包含建立 Go repository 的 workspace、啟動測試 task、透過 SSH 執行建置、暫停與恢復 task。網站也把 agent 描述為具有狀態、會等待模型或工具回應，並宣稱透過 actor、資源共用與 checkpoint 支援大量並行任務；「每個叢集可達數十億任務」與「低於一秒恢復」是專案頁面的設計目標與產品說法，頁面沒有提供獨立壓力測試資料。

AX 建立在 Agent Substrate 之上，開發者仍需自行設定可連線的主機、憑證與模型服務。網站列出網路隔離和資源限制，但目前公開頁面沒有交代完整的多租戶權限模型、故障恢復邊界或實際部署成本。

- 來源：[agentexecutor.io](https://agentexecutor.io)

## Kev 釋出 0.8B、4B、9B 決策模型，支援本機推理與機率輸出

開源專案 Kev 以 Qwen3.5 為 base model，提供 0.8B、4B 與 9B 三個模型、訓練程式和評測資料，API 對應 TypeSafe 的 System One 格式。模型針對 choice、yes/no 與 score 類型的決策問題輸出答案、機率與 confidence，可在 CUDA、ROCm 與 Apple Silicon 上執行。

專案 README 的新來源測試列出 Kev-9B accuracy 為 0.822（development）與 0.852（test），Brier score 為 0.286 與 0.237；Jev 在同一表格的新來源 development accuracy 為 0.857，但兩者訓練資料未知，因此作者沒有把這列成受控比較。專案也說明，溫度校準讓 Kev-9B 的 calibration error 從 0.106 降到 0.042，但仍有 4.0% 的新來源問題會得到至少 0.9 的錯誤機率。

限制條件包括選項順序可能改變答案、模型在 Apple Silicon 上較慢、訓練資料的 state 長度上限為 384 tokens，以及以 5% 錯誤預算可自動化的決策比例低於 Jev。README 明確要求使用者在自己的資料上測試，再決定機率門檻。

- 來源：[github.com](https://github.com/jaredpalmer/kev/tree/main)

## Anthropic 開放聚合 Claude 使用資料，讓外部團隊自行設計研究問題

Anthropic 公布一項試行計畫，讓 Stanford SALT Lab、Oxford Human Information Processing Lab 與 METR 透過 Anthropic Insights 分析約 250,000 段 2026 年 4 至 5 月的 Claude.ai 或 Claude Code 對話。外部研究者只取得聚合結果，不接觸原始對話；公司表示研究團隊可自行設計問題，Anthropic 的合約審查權限限於使用者隱私、可能協助違反使用政策的資訊、機密資料與研究準確性。

目前公開的結果包含：人們把高風險工作帶給 AI、合作時通常仍會直接指揮和監督、使用者在合作過程中常遇到摩擦，以及能力較高的模型可能為使用者節省更多時間。Oxford 團隊仍在完成研究報告，METR 的下一步是測量 AI 對研究工作的加速幅度；這些項目尚不是完整的獨立研究結論。

Anthropic 同時公開各計畫的聚合資料與隱私審查附錄，但公司說明，研究流程需要隱私審查、資料分類與法律檢查，速度和資源成本都高於內部研究。計畫後續能否擴大，取決於可支援的研究類型、同時執行的研究數量，以及研究者取得資料的條件。

- 來源：[anthropic.com](https://www.anthropic.com/research/enabling-independent-research)

## Claude 的價值表達會隨模型與語言改變

Anthropic 以 309,815 段 Claude.ai 對話研究模型與語言差異，樣本平均分配給 Sonnet 4.6、Opus 4.6、Opus 4.7，以及 Claude 平台上 20 種常用語言。研究團隊先把 3,307 個價值分類成 339 個高階價值，再用模型標記對話中的價值是否出現，最後以四條軸線整理差異：服從與謹慎、溫暖與嚴謹、深度與簡潔、坦率與執行。

研究頁面表示，四條軸線合計解釋對話價值差異的 15%。在模型比較中，Opus 4.7 平均較偏向謹慎與深度，Sonnet 4.6 較偏向服從、溫暖與簡潔；在語言比較中，Claude 以英文對話較偏向謹慎與深度，以阿拉伯文較偏向服從與簡潔，溫暖與嚴謹軸線的語言差異最大。

研究團隊指出，這些差異相對於單一對話之間的變化仍然小，而且四條軸線只涵蓋部分變異。資料來自兩週期間的對話，價值標記由 Claude 的隱私保護分析工具產生；研究尚未確認差異由訓練資料、文化語境或其他因素造成，也沒有測量這些輸出差異對使用者決策品質或信任的實際影響。

- 來源：[anthropic.com](https://www.anthropic.com/research/claude-values-models-languages)
