近三天的新聞焦點不只在模型分數，而在模型被放進什麼樣的工作流：Google 把 Gemini 4 Argon 先交給受信任的資安防禦者，Cloudflare 發布可輸出結構化決策的開放權重模型，DeepSeek 則把桌面代理做成可插拔的平台。Anthropic 刊出的科學案例也把限制寫得很清楚：模型能大量處理計算與程式，但研究問題是否重要，仍由領域專家判斷。

## 🔥 Gemini 4 Argon 先向受信任的資安防禦者開放

Google 9 月 30 日公布 Gemini 4 Argon，主打長流程軟體工程、金融與法律工作，以及資安防禦。官方資料列出的輸出上限為 100 萬 token，高於前一代的 64K；API 導入價格為每百萬輸入 token 2 美元、輸出 token 10 美元，導入期後調整為 4 美元與 20 美元。

Google 表示，Argon 在 DeepSWE v1.1 得分 77.9%，在 AutomationBench 得分 51.3%，在 LVBench 得分 91.7%；這些數字來自 Google 列出的各項評測，文章沒有提供同一頁面上的完整測試設定與獨立重現結果。Google 也展示一個 libgav1 案例：代理將 Rust 移植版本的 3.2 萬行 SIMD 程式碼改寫為安全 Rust，宣稱速度達到原 Rust 版本的 2.7 倍，且輸出相同。

資安能力方面，Google 表示 Argon 能尋找、驗證並修補軟體漏洞，在 CWE-bench v1 得分 68%，與另一模型並列第一。發布初期只透過 Fairwind Program 向受信任的資安防禦者提供，並表示這些使用者將取得沒有資安防護限制的版本；一般開發者、企業與消費者要等後續分階段開放。誰被列為受信任防禦者、如何審查，以及外部使用者能否驗證這些結果，公告沒有完整說明。

## Cloudflare 發布 Clef：用開放權重模型處理代理的結構化決策

Cloudflare 發布 Clef 與 Clef-flash，定位不是用來長篇生成文字，而是讓代理根據輸入回傳限定格式的分類、分數、選項與機率。兩個模型以 Apache 2.0 授權放在 Hugging Face，也可透過 Workers AI 使用；Cloudflare 同時推出為 Clef 做客製化訓練的服務，初期由工程團隊協助，之後預計提供自助平台。

Cloudflare 的說法是，Clef 在其列出的決策模型評測中，部分項目高於 Jev 等模型；Clef 的 context window 為 64K，Clef-flash 為低延遲版本。Cloudflare 以內部威脅情報流程作例子：模型把網站抓取、渲染與分類合計在 2.2 秒完成，對照同一流程使用 gpt-oss-120b 的 4.7 秒；這是公司自己的工作流測試，不是普遍任務完成時間。

技術上，Cloudflare 表示 Clef 以 Qwen 為基礎，先進行 prefill，再對符合 schema 的選項平行評分，避免逐 token 生成中間文字。這類模型適合把「是否緊急」「交給哪個團隊」等決定接入程式流程，但把人的判斷轉成機率和固定 schema 後，仍需要決定哪些情況可以自動執行、哪些情況必須交給人。Cloudflare 的產品同時會透過 AI Gateway 蒐集請求資料供訓練使用；官方表示不會讀取、儲存或用請求與回應訓練，除非使用者選擇其微調產品。

- 來源：[blog.cloudflare.com](https://blog.cloudflare.com/clef-decision-models/)

## DeepSeek Harness 公開預覽，桌面代理以 plugin 架構擴充

DeepSeek 將 DeepSeek Harness 開放全球公開預覽，提供 macOS Apple silicon 與 Windows 64-bit 桌面版本，程式碼以 MIT 授權放在 GitHub。產品建構在 Cordis 的「everything is a plugin」架構上，支援日常工作、程式撰寫、研究、背景任務與自訂 plugin，也能從程式碼啟動 Web UI。

官方展示的功能包含 workspace 檔案處理、工具呼叫軌跡、agent loop、subagents、排程任務，以及透過 Creator mode 產生和安裝 plugin。頁面中的示例顯示，使用者要求製作 Pomodoro plugin 後，系統讀取開發技能、修改多個檔案、安裝 plugin，再驗證運作狀態；這是產品展示流程，不代表所有 plugin 都有相同的權限或可靠度。

Harness 的可擴充性也把風險移到 plugin 與本機環境：官方頁面列出 Terminal、排程和 agent teams 等功能，其中部分標示為 Experimental。公開預覽目前提供的是一套可下載與自架的代理工作流，實際能否安全地處理檔案、指令與背景任務，取決於權限設定、plugin 來源與使用者審查，不能只看模型名稱。

- 來源：[deepseek.com](https://www.deepseek.com/en/harness/)

## Anthropic 刊出 BootLoops 案例：模型能做計算，專家仍決定問題是否重要

Anthropic 刊登物理學家 Matthew Schwartz 的客座文章，介紹開源工具 BootLoops 如何把 Claude 放進數學物理、生態學、人口遺傳學與語言學的計算工作。文章描述的流程包括把論文中的方法轉成可執行程式、搜尋可處理的問題、重現既有結果，再由不同領域的專家確認結果是否具有科學意義。

文章列出一項生態學案例：BootLoops 解出與中性生物多樣性理論有關的方程，套用資料後得到巴拿馬 Barro Colorado Island 森林物種組成變化速度約為理論預測的 4.5 倍；生態學家 James O’Dwyer 之後協助把問題改成能描述自然選擇、競爭與物種差異的模型。另一項人口遺傳學工作分析了 1000 Genomes Project 中 57 億組鄰近突變，文章稱找到基因轉換機制的證據；這些結果仍在延伸與驗證中。

作者也記錄了限制：Claude 常把技術上正確但科學價值有限的結果說得很重要，需要領域專家重新定義問題；長時間計算會遇到上下文壓縮、錯估時間與「宣告完成」等失敗模式。文章提到三個月內協調 36 篇手稿、18 個領域、19 名共同作者，並使用多個 Google Cloud 虛擬機與 GitHub、Overleaf 儲存中間結果。BootLoops 不是 Anthropic 的專案，由 Schwartz 維護；文章也披露他當時是 Anthropic 的訪問研究員。

- 來源：[anthropic.com](https://www.anthropic.com/research/claude-shaped-science)
